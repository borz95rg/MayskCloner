# Maysk App Cloner

Менеджер профилей приложений. Он хранит название и ссылку на установленное приложение, открывает системную функцию клонирования телефона и помогает создать ярлык запуска.

## Что приложение делает

- Показывает запускаемые приложения, доступные Android для этого приложения.
- Хранит локальные профили и позволяет задать имена.
- Пытается открыть известные экраны клонирования некоторых прошивок.
- Создаёт ярлык, который запускает исходное установленное приложение.
- Экспортирует настройки и профили; при включённой защите шифрует копию паролем.
- Проверяет GitHub Releases и предлагает установить совместимое обновление.

Системное клонирование зависит от производителя и модели телефона. Ярлык сам по себе не создаёт отдельную копию, рабочий профиль Android и отдельные данные. Приложение не пересобирает чужие APK, не запускает их внутри себя и не обходит защиту.

## Защита и резервные копии

- PIN приложения сохраняется как соль и PBKDF2-хеш; после ухода приложения в фон PIN запрашивается снова. После пяти неверных попыток ввод блокируется на 30 секунд.
- «Скрыть экран в недавних приложениях» включает системный `FLAG_SECURE` для окна приложения.
- Зашифрованная резервная копия использует AES-GCM и пароль, который не сохраняется приложением. PIN приложения в резервную копию не включается.
- Резервная копия содержит только настройки и метаданные профилей, не данные самих приложений, аккаунты или их файлы.

## Сборка и публикация APK

В `.github/workflows/build.yml` находится единый workflow:

- Push в `main`/`master` создаёт installable debug APK как артефакт запуска Actions.
- Если добавлены секреты подписи, дополнительно собирается signed release APK.
- Для публикации в Releases создайте тег формата `v1.0.N` и добавьте постоянный ключ подписи.

Секреты Actions:

- `KEYSTORE_BASE64`
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`

Теги без постоянного ключа подписи завершатся ошибкой: публикация неподписанного или меняющегося debug-ключа как обновления может лишить установленные копии возможности обновляться.

Для списка установленных приложений используется `QUERY_ALL_PACKAGES`. При публикации в Google Play нужно обосновать широкую видимость пакетов согласно требованиям магазина; для прямой установки APK это ограничение не применяется.
