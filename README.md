# Maysk App Cloner

Менеджер клонов экосистемы **Maysk**. Помогает создавать копии игр и приложений штатными
средствами телефона — **без пересборки чужих APK, без VPN и без root**. Собирается на
GitHub Actions в APK и умеет обновляться само (как Maysk Music и Maysk Files).

## Как это работает

«Клонирование» выполняется средствами, которые уже есть в Android и в прошивке телефона:

1. **Встроенное клонирование производителя** — у большинства телефонов есть своя функция
   (Samsung Dual Messenger, Xiaomi «Клонирование приложений», Huawei App Twin, Oppo/Realme/vivo
   «Клонирование приложений»). Приложение открывает нужный экран настроек в один тап.
2. **Ярлык на рабочий стол** — быстрый запуск выбранного приложения.
3. **Рабочий профиль Android** — отдельное пространство, где оно доступно.

Maysk App Cloner — это удобная витрина и менеджер поверх этих способов: список приложений в
фирменном стиле, выбор способа, оформление ярлыка, резервная копия настроек, обновления.

### Чего приложение НЕ делает
- Не пересобирает и не переподписывает чужие APK.
- Не запускает чужой код внутри себя (без виртуализации) и не обходит защиту приложений.
- Не меняет сетевые запросы и не использует VPN.

Поэтому «клон как вторая установленная копия» создаётся именно встроенной функцией телефона —
если её на устройстве нет, доступны ярлык и рабочий профиль.

## Экраны

Главная, Мои клоны, карточка клона (Запустить / Клонировать встроенной функцией / Ярлык /
Оформление / Резервная копия / Удалить профиль), Оформление (способ, название, стиль ярлыка),
Безопасность (PIN, скрыть клоны, подтверждение удаления), Резервная копия (экспорт/импорт),
Настройки (тема, акцент, обновления) и О приложении.

## Как загрузить через GitHub Desktop и получить APK

1. Создайте репозиторий (например `MayskCloner`) и загрузите в него эти файлы через GitHub Desktop.
2. **Сборка идёт даже без секретов** — тогда APK подписывается отладочным ключом (для установки
   этого достаточно). Для обновлений «по воздуху» нужна постоянная подпись: добавьте 4 секрета
   (Settings → Secrets and variables → Actions → New repository secret):
   - `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` — те же, что в других
     проектах Maysk.
3. Push запускает сборку. Готовый `MayskCloner-1.0.N.apk` появится в разделе Releases.

> Если добавите секреты позже — просто запустите сборку заново (Actions → Build & Release → Re-run).
> APK с отладочной подписью и APK с вашим ключом нельзя обновить один поверх другого — переустановите.

## Структура

```
app/src/main/java/com/maysk/cloner/
├── data/     — настройки, профили (CloneProfile), список приложений, менеджер клонов, резервные копии
├── update/   — обновления из GitHub Releases
└── ui/       — тема и экраны (Compose)
design/        — общая дизайн-система Maysk
.github/workflows/build.yml — сборка и публикация APK
```

## Ограничения
- Встроенное клонирование есть не на всех телефонах и называется по-разному; на «чистом» Android
  (Pixel) его нет — тогда используйте ярлык или рабочий профиль.
- Открываемый экран клонирования зависит от прошивки: если точный экран не найден, приложение
  открывает «О приложении», где у многих прошивок есть пункт клонирования.
