# Maysk App Cloner

Приложение экосистемы **Maysk** для управления Google-запросами у выбранных приложений и игр.
Собирается на GitHub Actions в подписанный APK и умеет обновляться само (как Maysk Music и Maysk Files).

## Как это работает

Главная функция — **локальный файрвол** на самом телефоне (на основе VpnService).
Для выбранного приложения в режиме «Без автоматического Google-запроса» файрвол перестаёт
пропускать обращения именно к серверам Google/microG. Приложение запускается как обычно, но
окно входа Google не появляется — запрос просто не доходит до сервера. Собственный логин игры
работает, потому что идёт на другой адрес.

Это законный способ: управление сетью на собственном устройстве (как NetGuard/Blokada).
**Код сторонних приложений не изменяется, APK не пересобираются, токены не подделываются,
пароли не перехватываются, Play Integrity не обходится.**

### Чего приложение НЕ делает
- Не пересобирает и не переподписывает чужие APK.
- Не запускает две копии одной игры — для изоляции данных используйте профиль Android.
- Не вмешивается в код и защиту сторонних приложений.

«Клон» здесь = профиль установленного приложения с отдельными настройками Google и авторизации.

## Режимы (для каждого клона отдельно)

- **Стандартный** — Google Services работают как обычно.
- **Без автоматического Google-запроса** — файрвол блокирует необязательные обращения к Google
  (проверка связи, вход в аккаунт, Play Games, microG, переход в Play, внешний браузер — каждое
  отключается отдельным переключателем). Собственный вход приложения не трогается.
- **Совместимость** — ничего не ограничивается (если блокировка ломает приложение).

При первом включении режима «Без Google-запроса» Android один раз спросит разрешение на VPN —
это нужно для работы локального файрвола. Весь трафик остаётся на устройстве.

## Как загрузить через GitHub Desktop и получить APK

1. Создайте репозиторий (например `MayskCloner`) и загрузите в него эти файлы через GitHub Desktop.
2. Добавьте 4 секрета подписи (Settings → Secrets → Actions): `KEYSTORE_BASE64`,
   `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` — те же, что и в других проектах Maysk.
3. Push запускает сборку. Готовый `MayskCloner-1.0.N.apk` появится в разделе Releases.
4. Приложение само проверяет Releases и предлагает обновиться.

## Структура

```
app/src/main/java/com/maysk/cloner/
├── engine/   — файрвол: VpnService (DNS-sinkhole), списки доменов, контроллер
├── data/     — настройки, профили (CloneGoogleSettings), список приложений, резервные копии
├── update/   — обновления из GitHub Releases
└── ui/       — тема и экраны (Compose)
design/        — общая дизайн-система Maysk
.github/workflows/build.yml — сборка и публикация APK
```

## Ограничения
- Блокировка работает на уровне DNS. Приложения, которые ходят к Google по «вшитым» IP или через
  собственный DNS-over-HTTPS, этим способом не перекрыть полностью.
- На Android 10+ правила применяются точно к конкретному приложению; на более старых версиях —
  к общему списку выбранных приложений.
